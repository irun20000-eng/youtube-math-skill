🎯 원순열은 공식 암기가 아니라 망망대해처럼 자리를 구별할 수 없는 상태의 이해. ① 다 구별된다 치고 지른 뒤 회전수로 나눔 ② 한 명 앉혀 기준점 세우고 자리종류$\times(n{-}1)!$. 확통은 플랜 B로 더블 체크.

📌 도입: 영상이 던진 통찰

예시 — 원순열은 "구별이 안 되는" 상태

핵심: 원순열이 어려운 이유는 우리가 사방이 구별되는 방에 살기 때문. 망망대해 한가운데에 떠 있다고 상상하면 동서남북(자리)이 구별되지 않는다.

📖 두 가지 접근

① 나눗셈(회전수로 보정): 일단 자리가 다 구별된다 치고 순열($n!$)로 지른 뒤, 실제로 구별 안 되는 회전수로 나눈다. 예: 원형 $4$명 → $\dfrac{4!}{4}$.

② 기준점(자리의 종류 $\times(n-1)!$): 한 명이 앉아 기준을 세우면 나머지는 구별됨. 예: 원형 $4$명 → 자리 종류 $1\times3!$.

둘 다 같은 답: $\dfrac{4!}{4}=6=1\times3!$.

강사: 공식 외우지 말고 "지르고 나눈다" 또는 "기준 세우고 곱한다" 원리로. 수능은 기준점 방식이 빠를 때가 많다.

💡 개념 설명 (회전수 나눗셈 · 기준점 · 자리의 종류)

① 왜 나누는가 — 회전수

원형 $n$자리는 돌리면 겹친다. 자리를 다 구별해 $n!$ 로 세면 같은 배열을 회전수만큼 중복해 센 것 → 그만큼 나눈다.

예: 원형 $4$명: $4!=24$ 를 회전수 $4$ 로 → $6$. (한 배열을 4번 돌려 4번 중복 셈)

② 기준점 — 한 명이 앉으면 구별 시작

망망대해에 첫 사람이 자리 잡으면 그를 기준으로 나머지 위치가 좌·우로 구별됨.

서로 다른 자리의 종류 $\times\,(n-1)!$. 원형은 자리 종류 $1$ → $(n-1)!$.

원순열 $=\dfrac{n!}{n}=(n-1)!=\text{(자리의 종류)}\times(n-1)!$ (원형은 종류 1)

③ 자리의 종류 — 회전해도 안 겹치는 자리 수

도형이 원이 아니면 회전 대칭이 낮아 자리 종류가 여러 개. 그만큼 첫 사람의 선택지가 늘어난다.

직사각형 탁자(긴 변 2·짧은 변 1, 6인): $180°$ 회전에서만 겹침 → 회전수 $2$. 자리 종류는 (긴 변 좌·긴 변 우·짧은 변) $3$ 종류.

나눗셈: $\dfrac{6!}{2}=360$. 기준점: $3\times5!=360$. 일치.

④ 플랜 B — 확통은 더블 체크

확통은 자기 풀이가 맞는지 불안하다. 반드시 다른 논리(조합+팩토리얼) 로 검산하는 습관.

📝 수준별 문항 (8문항 — 기초 2 · 기본 2 · 심화 2 · 수능 대비 2)

🟢 기초

기초 1 — 원순열 기본

문제: $5$ 명을 원형 탁자에 앉히는 경우의 수를 구하시오.

📖 풀이 보기

나눗셈 $\dfrac{5!}{5}=\dfrac{120}{5}=24$. 기준점 $(5-1)!=4!=24$.

정답: $24$

기초 2 — 두 방식 일치 확인

문제: 원형 $4$명 배열을 $\dfrac{4!}{4}$ 와 $(4-1)!$ 로 각각 계산해 같음을 보이시오.

📖 풀이 보기

$\dfrac{4!}{4}=\dfrac{24}{4}=6$. $(4-1)!=3!=6$. 같음.

정답: 둘 다 $6$ (회전수 나눗셈 = 기준점)

🔵 기본

기본 1 — 직사각형 탁자 (두 방식)

문제: 긴 변에 $2$명, 짧은 변에 $1$명씩 앉는 직사각형 $6$인 탁자에 $6$명을 앉히는 경우의 수를, 나눗셈과 기준점 두 방식으로 구하시오.

📖 풀이 보기

나눗셈: $180°$ 회전만 겹침 → 회전수 $2$ → $\dfrac{6!}{2}=\dfrac{720}{2}=360$.

기준점: 자리 종류 $3$(긴 좌·긴 우·짧은) → $3\times5!=3\times120=360$.

정답: $360$ (두 방식 일치)

기본 2 — 자리의 종류 판단

문제: 정삼각형 탁자(각 변에 $2$명씩, $6$인)에서 회전수와 자리의 종류를 구하시오.

📖 풀이 보기

정삼각형은 $120°$ 마다 겹침 → 회전수 $3$. 한 변 안에서 좌·우 구별 → 자리 종류 $6\div3=2$.

검산: $\dfrac{6!}{3}=240$, $2\times5!=240$ 일치.

정답: 회전수 $3$, 자리 종류 $2$

🟠 심화

심화 1 — 원+정삼각형 색칠 (영상)

문제: 원 안에 정삼각형 형태로 $7$개 영역(가운데 $1$·안쪽 $3$·바깥 $3$)이 나뉘어 있다. $7$가지 색을 한 영역에 하나씩 칠하는 경우의 수를 나눗셈·기준점 두 방식으로 구하시오.

📖 풀이 보기

나눗셈: $7$영역 다 구별 치고 $7!$, 정삼각형 회전수 $3$ → $\dfrac{7!}{3}=\dfrac{5040}{3}=1680$.

기준점: 유일한 가운데에 색 $1$개 선택($7$), 남은 자리 종류 $2$(안·바깥) → 첫 색이 $2$ 중 선택, 기준 생겨 나머지 $5!$ → $7\times2\times5!=7\times2\times120=1680$.

정답: $1680$

심화 2 — 플랜 B (조합+팩토리얼)

문제: 심화 1 을 "가운데 색 → 안쪽 3색 선택 → 안쪽 원순열 → 바깥쪽 배열"로 다시 풀어 $1680$ 임을 확인하시오.

📖 풀이 보기

가운데 색 ${}_7C_1=7$. 안쪽에 칠할 $3$색 선택 ${}_6C_3=20$. 안쪽 $3$영역(정삼각형=원순열) $2!$. 바깥 $3$영역에 남은 $3$색 배열 $3!$.

$7\times20\times2!\times3!=7\times20\times2\times6=1680$.

정답: $1680$ (플랜 B 일치 → 더블 체크 성공, 개념 ④)

🔴 수능 대비

수능 대비 1 — 조건 붙은 원순열

문제: $6$명(남 $3$·여 $3$)을 원형으로 앉히되 남녀가 교대로 앉는 경우의 수를 구하시오.

📖 풀이 보기

기준점: 남자 $1$명이 앉아 기준 → 남자 나머지 $2$명 배열 $2!$. 남자 사이 $3$자리에 여자 $3$명 배열 $3!$.

$2!\times3!=2\times6=12$.

플랜 B: 남자 원순열 $(3-1)!=2$, 그 사이 여자 $3!=6$ → $2\times6=12$ 일치.

정답: $12$

수능 대비 2 — 정사각형 탁자

문제: 정사각형 탁자(각 변 $1$명, $4$인)에 $4$명을 앉히는 경우의 수를 구하고, 원형 $4$인과 같은지 설명하시오.

📖 풀이 보기

정사각형은 $90°$ 마다 겹침 → 회전수 $4$ → $\dfrac{4!}{4}=6$. 자리 종류 $1$ → $(4-1)!=6$.

원형 $4$인과 회전 대칭이 같아($90°\times4$) 결과 동일 $6$.

정답: $6$ (정사각형 = 원형 4인, 회전수 4로 동일)
