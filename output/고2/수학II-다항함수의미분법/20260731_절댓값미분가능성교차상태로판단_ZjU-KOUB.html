예시 — "꺾지 마라", 교차 상태를 봐라

핵심 명제: 절댓값 함수의 미분 가능성은 그래프를 꺾어 그리는 것이 아니라, 함수가 기준 직선과 어떤 상태로 만나는지(교차 / 접점 / 3중근)로 판단한다.

📖 교차 상태 3종

단순 교차(부호 바뀌며 관통): $|f|$ 는 그 점에서 미분 불가능. (꺾임 발생)

접점(부호 안 바뀌고 닿기만, 중근): $|f|$ 는 미분 가능.

3중근(부호 바뀌지만 기울기 0으로 관통): $|f|$ 는 미분 가능.

정확한 해석: "미분 가능 = 접한다" ❌ → "미분 가능 = 단순 교차하지 않는다" ⭕. (강사: "교차하면 미분 불가능, 교차 안 하면 가능")

💡 개념 설명 (교차 상태 · 곱의 미분 가능성)

① 왜 단순 교차에서 미분 불가능한가

$f$ 가 어떤 점에서 부호를 바꾸며 관통(단순근)하면, $|f|$ 는 그 점에서 $x$축 아래 부분이 위로 접혀 뾰족점이 생긴다 → 좌·우 미분계수 부호가 달라 미분 불가.

예: $y=|x|$ 는 $x=0$ 에서 $f=x$ 가 단순 교차(부호 $-\to+$) → 뾰족점 → 미분 불가.

② 접점·3중근은 왜 미분 가능한가

접점(중근): $f$ 가 $(x-a)^2$ 인수 → $x=a$ 좌우로 $f$ 부호 안 바뀜 → $|f|=f$ (또는 $-f$) 로 매끄러움 → 미분 가능.

3중근: $f$ 가 $(x-a)^3$ 인수 → 부호는 바뀌지만 $x=a$ 에서 기울기 $0$ → 접힌 자리도 기울기 $0$ 으로 이어져 매끄러움 → 미분 가능.

③ 핵심 — 곱의 미분 가능성

$y=g(x)\cdot|h(x)|$ 에서 $|h|$ 가 $x=a$ 에서 꺾여도, $g(a)=0$ 이면 전체는 미분 가능.

예: $y=(x-a)|x-1|$ 가 모든 점에서 미분 가능 → $x=1$ 의 꺾임을 $(x-a)$ 가 $0$ 으로 눌러야 함 → $a=1$.

④ 실전 — 기준 직선과의 교차로 개형 세우기

$||f(x)|+c|$ 꼴은 $|f(x)|=-c$, 즉 $f(x)=\pm(-c)$ 인 기준 직선과의 교차 상태로 미분 불가점을 센다. 꺾어 그리지 말고 직선 교차만.

미분 불가점이 딱 하나(단순 교차 1개) 이려면, 나머지 교점은 접점 또는 3중근이어야 한다.

"$x=1$ 에서만 단순 교차, 다른 곳은 3중근" → 함수식을 $(x-1)(x-\alpha)^3$ 꼴로 미지수 구성.

📝 수준별 문항 (8문항 — 기초 2 · 기본 2 · 심화 2 · 수능 대비 2)

🟢 기초

기초 1 — 단순 교차의 미분 불가

문제: $y=|x-2|$ 가 미분 불가능한 점을 구하고 이유를 쓰시오.

📖 풀이 보기

$f=x-2$ 는 $x=2$ 에서 부호 $-\to+$ 로 단순 교차 → $|f|$ 는 $x=2$ 에서 뾰족점.

정답: $x=2$ (단순 교차 → 미분 불가)

기초 2 — 접점이면 미분 가능

문제: $y=|(x-1)^2|$ 가 $x=1$ 에서 미분 가능한지 판정하시오.

📖 풀이 보기

$(x-1)^2\ge0$ 이라 $|(x-1)^2|=(x-1)^2$. $x=1$ 좌우 부호 안 바뀜(접점) → 매끄러움.

정답: 미분 가능 (중근=접점, 부호 안 바뀜)

🔵 기본

기본 1 — |f| 미분 불가점 (단순근 vs 중근)

문제: $f(x)=x(x-3)^2$ 일 때 $y=|f(x)|$ 가 미분 불가능한 점을 모두 구하시오.

📖 풀이 보기

$f$ 의 근: $x=0$ (단순근, 부호 $-\to+$ 교차) → $|f|$ 미분 불가. $x=3$ (중근, 접점, 부호 안 바뀜) → 미분 가능.

정답: $x=0$ 뿐 (단순 교차만 미분 불가)

기본 2 — 곱의 미분 가능 조건

문제: $y=(x-a)|x-1|$ 이 모든 실수에서 미분 가능하도록 하는 상수 $a$ 를 구하시오.

📖 풀이 보기

$|x-1|$ 은 $x=1$ 에서 꺾임 → 그 점에서 앞 인수 $(x-a)=0$ 이어야 눌림 → $1-a=0$.

정답: $a=1$ (개념 ③)

🟠 심화

심화 1 — 기준 직선 교차로 미분 불가점 세기

문제: $f(x)=\tfrac12 x(x-3)^2$ 에 대해 $y=||f(x)|-2|$ 의 미분 불가능한 점의 개수를, 기준 직선 $f=0,\ f=2,\ f=-2$ 와의 단순 교차 개수로 설명하시오. (꺾지 말 것)

📖 풀이 보기

$||f|-2|$ 의 미분 불가점 = $|f|$ 가 $2$ 와 단순 교차하는 곳(=$f=\pm2$ 단순 교차) + $|f|$ 자체가 미분 불가한 곳($f=0$ 단순 교차, 즉 $x=0$).

$f=\tfrac12 x(x-3)^2$ 개형: $x=0$ 단순근(교차), $x=3$ 중근(접, $f=0$). $f=2$ 와 단순 교차 2회, $f=-2$ 와 단순 교차 1회(음수부).

정답: 단순 교차점의 총 개수 = 미분 불가점 수. (영상: 교차점 3개가 미분 불가) 핵심은 접점은 세지 않고 단순 교차만 센다는 것.

주의: 정확한 개수는 $f=\pm2$ 방정식의 실근 상태에 따라 달라지므로 그래프 개형으로 확정 필요(교사 검토). 여기서 익힐 것은 "단순 교차만 미분 불가" 원칙.

심화 2 — 3중근이면 미분 가능

문제: $f(x)=(x-1)^3$ 일 때 $y=|f(x)|$ 가 $x=1$ 에서 미분 가능한지 판정하시오.

📖 풀이 보기

$f=(x-1)^3$ 은 $x=1$ 에서 부호 바뀌며 관통(단순근 아님, 3중근). $f'(x)=3(x-1)^2$, $f'(1)=0$ → 접히는 자리 기울기 $0$.

좌우 미분계수 모두 $0$ 으로 이어져 매끄러움 → 미분 가능.

정답: 미분 가능 (3중근: 부호 바뀌어도 기울기 0, 개념 ②)

🔴 수능 대비

수능 대비 1 — 영상의 준킬러 (개형 → f(2))

문제: 최고차 계수 $1$ 인 사차함수 $f$ 와 실수 $k$ 에 대해 $g(x)=f(k)\cdot||f(x)|+f(2)|$ 가 $x=k$ 에서 미분 불가능한 $k$ 가 $1$ 뿐이다. 영상의 논리로 $f(2)$ 를 구하시오.

📖 풀이 보기

① $y=0$ 교점이 $k$ 면 $f(k)=0$ 이라 곱함수가 $0$ → 미분 가능. 즉 $x=1$ 은 $f=0$ 위가 아님.

② 미분 불가는 $|f(x)|=-f(2)$ 즉 기준 직선 $y=\pm f(2)$ 와의 단순 교차에서. ($f(2)<0$)

③ $x=2$ 는 $y=f(2)$ 위 → 여기선 미분 가능해야 하니 접함. $x=1$ 에서만 단순 교차, 나머지는 3중근.

④ 개형: $f(x)-(-f(2))=(x-1)(x-5)^3$ (x=1 교차, x=5 3중근).

⑤ $x=2$ 대입: $f(2)+f(2)=(2-1)(2-5)^3=-27$ → $2f(2)=-27$ → $f(2)=-\dfrac{27}{2}$.

정답: $f(2)=-\dfrac{27}{2}$

수능 대비 2 — f(7)까지 (영상식 후속)

문제: 위에서 $f(x)+f(2)=(x-1)(x-5)^3$ 이 확정되었을 때 $f(7)$ 을 구하시오.

📖 풀이 보기

$f(2)=-\tfrac{27}{2}$ 이므로 $f(x)=(x-1)(x-5)^3+\dfrac{27}{2}$.

$f(7)=(7-1)(7-5)^3+\dfrac{27}{2}=6\cdot8+\dfrac{27}{2}=48+\dfrac{27}{2}=\dfrac{123}{2}$.

검산: 최고차 $(x-1)(x-5)^3$ 의 $x^4$ 계수 $1$ ✓ (조건 충족). $f(2)=(1)(-27)+\tfrac{27}{2}=-\tfrac{27}{2}$ ✓.

정답: $f(7)=\dfrac{123}{2}$

✅ 학습자 가이드라인 · 검증

영상(시대수학 김성호)의 통찰 "꺾지 말고 교차 상태를 보라"를 중수준(하위 40%)도 따라오게 작성:

  • 교차 상태 3종(단순교차→불가 / 접점·3중근→가능) → 뾰족점·기울기 0으로 이유 설명 (개념 ①②, 기초·심화 2).
  • 곱의 미분 가능 → $(x-a)|x-1|$ 에서 $a=1$ (개념 ③, 기본 2).
  • 기준 직선 교차로 개형 → $x=1$ 교차·$x=5$ 3중근 → $f(2)=-\tfrac{27}{2}$, $f(7)=\tfrac{123}{2}$ (수능 대비 1·2, 순수 파이썬 검산).

다만 다음은 교사 검토 권장:

  • 심화 1의 정확한 개수 — $f=\pm2$ 방정식의 실근 상태에 따라 미분 불가점 수가 달라지므로 그래프 개형으로 확정 필요. 여기서 익힐 원칙은 "단순 교차만 미분 불가". (원칙 ★★★, 특정 개수 ★★)
  • 수능 대비 1의 개형 추론(x=5 3중근·비율)은 영상 논리를 따랐고, $f(2)=-\tfrac{27}{2}$·$f(7)=\tfrac{123}{2}$ 는 그 식으로 검산 완료. 원문제의 조건 전체 정합성은 고난도라 교사 확인 권장. (확신도 ★★☆)
  • "수능 대비"는 출제 패턴 라벨일 뿐 실재 기출이 아닙니다.
