절댓값 극한 $\dfrac{f(x)}{|x|}$ — 미분계수로 인수 개수 추론

🎯 좌·우극한 노가다 대신 식 분리: $\dfrac{f(x)}{|x|}=\dfrac{f(x)}{x}\cdot\dfrac{x}{|x|}$. 부호 갈리는 $\dfrac{x}{|x|}$ 에 곱해 극한이 존재하려면 $f'(0)=0$. $f(0)=0,f'(0)=0$ → 원점서 접함 → $x^2$ 이상 인수.

📌 도입: 영상이 던진 통찰

예시 — $\dfrac{f(x)}{|x|}$ 극한이 존재할 조건

문제: 다항함수 $f$ 에 대해 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|}$ 이 존재한다. $f$ 는 원점에서 어떤 조건을 만족하는가?

📖 풀이 보기 (식 조작 → 미분계수)

STEP 1 — 조작: 좌·우극한 따로 대입 말고 분리: $\dfrac{f(x)}{|x|}=\dfrac{f(x)}{x}\cdot\dfrac{x}{|x|}$.

STEP 2 — 미분계수: $0/0$ 이려면 $f(0)=0$. 그러면 $\dfrac{f(x)}{x}=\dfrac{f(x)-f(0)}{x-0}\to f'(0)$.

STEP 3 — 부호 갈림: $\dfrac{x}{|x|}$ 는 우극한 $+1$, 좌극한 $-1$.

STEP 4 — 존재 조건: 극한 존재 → 우 $f'(0)\cdot1$ = 좌 $f'(0)\cdot(-1)$ → $f'(0)=-f'(0)$ → $f'(0)=0$.

정답: $f(0)=0$ 이고 $f'(0)=0$ → $f$ 는 원점에서 $x$축에 접함 → $x^2$ 이상을 인수로 가짐.

핵심: 절댓값 극한을 케이스 노가다 말고 미분계수 형태로 분리. 부호 갈리는 것에 곱해 존재하려면 계수가 $0$.

💡 개념 설명 (분리 · 부호 · 인수 개수)

① 선수 지식 — 미분계수 정의

$f(0)=0$ 이면 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{x}=\lim_{x\to0}\dfrac{f(x)-f(0)}{x-0}=f'(0)$.

$\dfrac{x}{|x|}$: $x>0$ 이면 $+1$, $x<0$ 이면 $-1$ (좌우 부호 갈림).

② 핵심 — 부호 갈림에 곱해 존재하려면 계수 0

$\dfrac{f(x)}{|x|}=\underbrace{\dfrac{f(x)}{x}}_{\to f'(0)}\cdot\underbrace{\dfrac{x}{|x|}}_{\pm1}$.

우극한 $=f'(0)\cdot(+1)$, 좌극한 $=f'(0)\cdot(-1)$.

극한 존재 ⟺ 좌=우 ⟺ $f'(0)=-f'(0)$ ⟺ $f'(0)=0$.

③ 핵심 — $f(0)=0,\ f'(0)=0$ = 인수 2개 이상

$f(a)=0$ 이고 $f'(a)=0$ 이면 $f$ 는 $(x-a)^2$ 을 인수로 가진다(원점에서 $x$축에 접함).

$f(0)=0,\ f'(0)=0 \iff f(x)=x^2\,q(x)$ (인수 $x$ 를 2개 이상)

④ 확장 — 분모 차수와 분자 인수 개수

분모가 $|x|^m$ (또는 홀수 차수 절댓값)일 때, 분자는 극한 존재를 위해 분모보다 인수를 1개 이상 더 가져야 한다.

감각: $\dfrac{f(x)}{|x|}$ 존재 → $f$ 는 $x^2$ 인수. $\dfrac{f(x)}{|x|^3}$ 존재 → $f$ 는 $x^4$ 인수(접힘+여유).

🟢 기초

기초 1 — x/|x| 좌우극한

문제: $\displaystyle\lim_{x\to0^+}\dfrac{x}{|x|}$ 와 $\displaystyle\lim_{x\to0^-}\dfrac{x}{|x|}$ 를 각각 구하시오.

📖 풀이 보기

$x>0$: $\dfrac{x}{x}=1$. $x<0$: $\dfrac{x}{-x}=-1$.

정답: 우극한 $1$, 좌극한 $-1$

기초 2 — 미분계수 정의

문제: $f(0)=0$ 인 미분가능 $f$ 에 대해 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{x}$ 를 $f'(0)$ 으로 나타내는 이유를 쓰시오.

📖 풀이 보기

$f(0)=0$ 이라 $\dfrac{f(x)}{x}=\dfrac{f(x)-f(0)}{x-0}$ → 미분계수 정의 → $f'(0)$.

정답: $f(0)=0$ 이므로 정의에 의해 $f'(0)$

🔵 기본

기본 1 — 존재 조건 도출

문제: 다항함수 $f$ 에 대해 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|}$ 이 존재할 때 $f(0)$ 과 $f'(0)$ 의 값을 구하시오.

📖 풀이 보기

$0/0$ → $f(0)=0$. 분리 후 $\dfrac{x}{|x|}$ 부호 갈림에 $f'(0)$ 곱 → 좌우 일치 위해 $f'(0)=0$.

정답: $f(0)=0$, $f'(0)=0$ (개념 ②)

기본 2 — 구체 함수로 확인

문제: $f(x)=x^2-2x$ 일 때 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|}$ 이 존재하는지 판정하시오.

📖 풀이 보기

$f(0)=0$ 이나 $f'(x)=2x-2$, $f'(0)=-2\neq0$.

우극한 $-2\cdot1=-2$, 좌극한 $-2\cdot(-1)=2$ → 좌$\neq$우 → 존재하지 않음.

정답: 존재 X ($f'(0)=-2\neq0$)

🟠 심화

심화 1 — 인수 개수 추론

문제: 다항함수 $f$ 에 대해 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|}$ 이 존재하면 $f$ 가 인수 $x$ 를 최소 몇 개 갖는지 쓰고, 그런 $f$ 의 예를 하나 드시오.

📖 풀이 보기

$f(0)=0,\ f'(0)=0$ → $x^2$ 인수 → 인수 $x$ 최소 2개.

예: $f(x)=x^2$ → $\dfrac{x^2}{|x|}=\dfrac{x^2}{|x|}=|x|\to0$ (존재).

정답: 최소 $2$개. 예 $f(x)=x^2$ (극한값 $0$)

심화 2 — 분모 차수가 높을 때

문제: $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|^3}$ 이 $0$ 이 아닌 값으로 존재하려면 $f$ 가 인수 $x$ 를 몇 개 가져야 하는지 추론하시오.

📖 풀이 보기

분모 $|x|^3$ 은 $x^3$ 규모. 극한이 유한·0아님이려면 분자도 $x^3$ 규모여야 하나, $|x|^3$ 은 $x\to0^\pm$ 에서 부호 갈림($\text{sgn}$) 문제 → 홀수 차수라 좌우 부호 처리 필요.

$f$ 가 $x^3$ 인수(3개)면 $\dfrac{x^3 q(x)}{|x|^3}=\dfrac{x^3}{|x|^3}q(x)=(\text{sgn }x)\,q(0)$ → 좌우 부호 갈려 존재 X. $x^4$ 인수(4개)면 $\dfrac{x^4}{|x|^3}=|x|\cdot(\cdots)\to0$ (존재, 값 0).

정답: 유한·0 아닌 값으론 불가(부호 갈림). 극한이 존재(값 0)하려면 $x$ 인수 최소 4개. (개념 ④)

주의: 절댓값의 홀수 차수는 좌우 부호 문제로 "0 아닌 극한"을 막는다. 존재시키려면 여유 인수로 $0$ 만들기.

🔴 수능 대비

수능 대비 1 — 미정계수 결합

문제: 최고차 계수 $1$ 인 삼차함수 $f$ 가 $\displaystyle\lim_{x\to0}\dfrac{f(x)}{|x|}=0$ 을 만족하고 $f(1)=2$ 이다. $f(x)$ 를 구하시오.

📖 풀이 보기

STEP 1: 극한 존재 → $f(0)=0,\ f'(0)=0$ → $x^2$ 인수. 삼차·최고차 $1$ → $f(x)=x^2(x-c)$.

STEP 2: $f(1)=1\cdot(1-c)=1-c=2$ → $c=-1$.

STEP 3: $f(x)=x^2(x+1)=x^3+x^2$.

검산: $f(0)=0$, $f'(x)=3x^2+2x$, $f'(0)=0$ ✓. $\dfrac{f(x)}{|x|}=\dfrac{x^2(x+1)}{|x|}=|x|(x+1)\to0$ ✓.

정답: $f(x)=x^3+x^2$

수능 대비 2 — 평행이동 형태

문제: 다항함수 $f$ 가 $\displaystyle\lim_{x\to2}\dfrac{f(x)}{|x-2|}$ 이 존재하도록 할 때 $f(2)$ 와 $f'(2)$ 를 구하시오.

📖 풀이 보기

$x-2=t$ 치환 → $\displaystyle\lim_{t\to0}\dfrac{f(t+2)}{|t|}$. 같은 논리로 $f(2)=0$, $f'(2)=0$.

정답: $f(2)=0$, $f'(2)=0$ ($f$ 는 $x=2$ 에서 $x$축에 접함, $(x-2)^2$ 인수)

핵심: $|x-a|$ 형태도 $x-a=t$ 치환으로 원점 논리 그대로.

✅ 학습자 가이드라인 · 검증

영상(수학강사 이정환, 쇼츠)의 논리를 중수준(하위 40%)도 따라오게 작성:

  • 식 분리 → 미분계수 → $\frac{f}{|x|}=\frac{f}{x}\cdot\frac{x}{|x|}$, 부호 갈림에 곱해 존재하려면 $f'(0)=0$ (개념 ①②, 기본 1).
  • 인수 개수 추론 → $f(0)=0,f'(0)=0$ → $x^2$ 인수. 분모 차수 높으면 더 많은 인수 (개념 ③④, 심화 1·2).
  • 미정계수·평행이동 → $f=x^3+x^2$, $|x-2|$ 형태까지 (수능 대비 1·2). 순수 파이썬 없이도 대입 검산 병기.
