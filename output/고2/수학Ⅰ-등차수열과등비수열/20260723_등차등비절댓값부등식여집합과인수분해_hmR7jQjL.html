🎯 "$n$이 1,2,5 뿐"은 나머지에선 반대 부등식(등호 포함)이라는 힌트. 등차 일반항을 $a_n=d(n-k)$ 로 공차 인수분해해 $d$ 를 약분, 등호 있는 부등식 먼저 풀어 상수 $k$ 를 특정.

📌 도입: 영상이 던진 문제

예시 — "n이 1,2,5 뿐"의 진짜 의미

문제: 공차 $d>0$ 인 등차수열 $\{a_n\}$, 공비 $2$ 인 등비수열 $\{b_n\}$ 이 $b_3=\tfrac13 d$ 를 만족한다. $|a_n|>b_n$ 을 만족하는 자연수 $n$ 이 $1,2,5$ 뿐일 때, $a_n$ 을 (미지수를 이용해) 결정하시오.

📖 풀이 보기

STEP 1 — 여집합 해석: "$1,2,5$ 뿐" = 나머지 자연수($3,4,6,\dots$)에선 $|a_n|\le b_n$ (등호 포함 반대 부등식). 경계 $3,4,6$ 을 먼저 본다.

STEP 2 — 등비 세우기: $b_n=b_3\cdot2^{\,n-3}=\tfrac13 d\cdot2^{\,n-3}$. ($b_3=\tfrac13 d$, $b_4=\tfrac23 d$, $b_6=\tfrac83 d$ …)

STEP 3 — 인수분해 식세우기: $a_n=dn+\alpha$ 로 두면 문자 둘. 대신 $a_n=d(n-k)$ 로 공차를 인수로 빼면 $|a_n|=d|n-k|$.

STEP 4 — $d$ 약분 + 등호 우선: $|a_n|\le b_n$ 에 $n=3,4$ 대입, 양변 $d>0$ 약분.

$n=3$: $|3-k|\le\tfrac13$ → $\tfrac83\le k\le\tfrac{10}{3}$. $n=4$: $|4-k|\le\tfrac23$ → $\tfrac{10}{3}\le k\le\tfrac{14}{3}$.

교집합 → $k=\dfrac{10}{3}$ (등호가 상수를 딱 하나로 확정).

정답: $a_n=d\left(n-\dfrac{10}{3}\right)$ (즉 $a_n=\tfrac{d}{3}(3n-10)$).

검증: $|a_n|>b_n$ 인 $n$ 을 실제로 세어보면 $1,2,5$ 뿐(아래 심화 2). $3,4,6$ 은 정확히 교점(등호).

💡 개념 설명 (여집합 · 인수분해 · 등호 우선)

① 큰 그림 — "~뿐이다"는 여집합 힌트

"부등식을 만족하는 $n$ 이 $\bigcirc,\bigcirc$ 뿐" 이라는 조건은, 그 외 모든 자연수에서 반대 부등식(등호 포함)이 성립한다는 강력한 힌트.

무수히 많은 나머지 중 경계가 되는 값(여기선 $3,4,6$)부터 따진다. $|a_n|$ 은 V자, $b_n$ 은 지수 곡선이라 교차가 여러 번.

② 선수 지식 — 등비수열 일반항

공비 $r$ 인 등비수열: $b_n=b_m\cdot r^{\,n-m}$. 한 항과 공비만 알면 전체가 결정.

여기선 $b_3=\tfrac13 d$, $r=2$ → $b_n=\tfrac13 d\cdot2^{\,n-3}$.

③ 핵심 — 공차를 인수로 빼는 식세우기

등차 일반항을 $a_n=dn+\alpha$ 로 두면 절댓값 부등식에 문자 $d,\alpha$ 둘이 남아 꼬인다.

등비 쪽에 $d$ 가 상수로 곱해져 있음($b_n=\tfrac{d}{3}\cdot2^{n-3}$)에 착안 → 등차도 $a_n=d(n-k)$ 로 공차를 밖으로.

그러면 $|a_n|=d|n-k|$ 이고 부등식 양변에서 양수 $d$ 가 약분되어 미지수가 $k$ 하나만 남는다.

④ 핵심 — 등호 있는 부등식을 먼저

$k$ 에 정수·자연수 조건이 없다 → 상수로 확정하려면 상한과 하한이 맞물려야 함.

등호 없는 부등식($>$)은 열린 범위만 줄 뿐. 등호 있는 부등식($\le$) 이라야 경계값에서 $k$ 를 특정할 여지.

$n=3$ 이 상한($k\le\tfrac{10}{3}$), $n=4$ 가 하한($k\ge\tfrac{10}{3}$) → 교집합이 한 점 $\tfrac{10}{3}$.

⑤ 대수 결과 ↔ 그래프 교점 상호 검증

$k=\tfrac{10}{3}$ 을 넣으면 $3,4,6$ 에서 $|a_n|=b_n$ (정확히 교점). 처음 스케치한 위치 관계와 일치함을 확인.

확인: $|a_6|=d\cdot\tfrac83$, $b_6=\tfrac83 d$ → 같음(교점). $|a_5|=\tfrac53 d>b_5=\tfrac43 d$ → $5$ 는 성립.

🟢 기초

기초 1 — 여집합 해석

문제: "부등식 $|a_n|>b_n$ 을 만족하는 자연수 $n$ 은 $1,2,5$ 뿐"이라는 조건을, $n=3,4,6$ 에 대한 부등식으로 바꿔 쓰시오.

📖 풀이 보기

"$1,2,5$ 뿐" → 그 외 자연수에선 반대 부등식(등호 포함): $|a_n|\le b_n$.

정답: $n=3,4,6$ 에서 $|a_n|\le b_n$ (개념 ①)

기초 2 — 등비수열 일반항

문제: 공비 $2$, $b_3=\tfrac13 d$ 인 등비수열 $\{b_n\}$ 의 $b_4$ 와 $b_6$ 을 $d$ 로 나타내시오.

📖 풀이 보기

$b_n=\tfrac13 d\cdot2^{\,n-3}$. $b_4=\tfrac13 d\cdot2=\tfrac23 d$, $b_6=\tfrac13 d\cdot2^3=\tfrac83 d$.

정답: $b_4=\tfrac23 d$, $b_6=\tfrac83 d$

🔵 기본

기본 1 — 인수분해 식세우기의 이점

문제: 등차수열을 $a_n=d(n-k)$ 로 둘 때 $|a_n|$ 을 쓰고, $|a_n|\le b_n$ 에서 $d$ 가 약분되는 과정을 보이시오. ($d>0$)

📖 풀이 보기

$|a_n|=|d(n-k)|=d|n-k|$ ($d>0$).

$d|n-k|\le \tfrac{d}{3}\cdot2^{\,n-3}$ → 양변 $\div d$ → $|n-k|\le\tfrac13\cdot2^{\,n-3}$.

정답: $d$ 약분 후 $|n-k|\le\tfrac13\cdot2^{\,n-3}$ — 미지수 $k$ 만 남음 (개념 ③)

기본 2 — 절댓값 부등식 (한 값 대입)

문제: $|n-k|\le\tfrac13\cdot2^{\,n-3}$ 에 $n=3$ 을 대입해 $k$ 의 범위를 구하시오.

📖 풀이 보기

$n=3$: $|3-k|\le\tfrac13\cdot2^0=\tfrac13$ → $-\tfrac13\le 3-k\le\tfrac13$ → $\tfrac83\le k\le\tfrac{10}{3}$.

정답: $\tfrac83\le k\le\tfrac{10}{3}$

🟠 심화

심화 1 — 등호 부등식으로 $k$ 확정

문제: $|n-k|\le\tfrac13\cdot2^{\,n-3}$ 에 $n=3$ 과 $n=4$ 를 대입해 $k$ 를 확정하시오.

📖 풀이 보기

$n=3$: $\tfrac83\le k\le\tfrac{10}{3}$ (상한 $\tfrac{10}{3}$).

$n=4$: $|4-k|\le\tfrac13\cdot2=\tfrac23$ → $\tfrac{10}{3}\le k\le\tfrac{14}{3}$ (하한 $\tfrac{10}{3}$).

교집합: $k=\dfrac{10}{3}$.

정답: $k=\dfrac{10}{3}$ (개념 ④ — 등호가 상수 특정)

심화 2 — 1,2,5만 성립함을 검증

문제: $k=\tfrac{10}{3}$ 일 때 $|a_n|>b_n$, 즉 $|n-\tfrac{10}{3}|>\tfrac13\cdot2^{\,n-3}$ 이 $n=1,2,5$ 에서만 성립함을 $n=1\sim6$ 에 대해 확인하시오.

📖 풀이 보기

좌변 $|n-\tfrac{10}{3}|$ vs 우변 $\tfrac13\cdot2^{\,n-3}$:

$n=1$: $\tfrac73$ vs $\tfrac1{12}$ → $>$ ✓ / $n=2$: $\tfrac43$ vs $\tfrac16$ → $>$ ✓

$n=3$: $\tfrac13$ vs $\tfrac13$ → $=$ (성립 X) / $n=4$: $\tfrac23$ vs $\tfrac23$ → $=$ (X)

$n=5$: $\tfrac53$ vs $\tfrac43$ → $>$ ✓ / $n=6$: $\tfrac83$ vs $\tfrac83$ → $=$ (X)

정답: $>$ 성립은 $n=1,2,5$ 뿐 → 조건과 일치. $3,4,6$ 은 교점.

🔴 수능 대비

수능 대비 1 — $d$ 까지 결정 (완결)

문제: 위 조건에 더해 $a_5-b_5=1$ 일 때 공차 $d$ 와 $a_n,\ b_n$ 을 구하시오.

📖 풀이 보기

$a_5=d(5-\tfrac{10}{3})=\tfrac53 d$, $b_5=\tfrac13 d\cdot2^2=\tfrac43 d$.

$a_5-b_5=\tfrac53 d-\tfrac43 d=\tfrac13 d=1$ → $d=3$.

$a_n=3(n-\tfrac{10}{3})=3n-10$, $b_n=\tfrac13\cdot3\cdot2^{\,n-3}=2^{\,n-3}$.

검산: $a_5=5$, $b_5=4$, $a_5-b_5=1$ ✓.

정답: $d=3$, $a_n=3n-10$, $b_n=2^{\,n-3}$

수능 대비 2 — 같은 논리, 다른 조건

문제: $d>0$ 등차 $\{a_n\}$, 공비 $2$ 등비 $\{b_n\}$, $b_2=\tfrac12 d$. $|a_n|>b_n$ 인 $n$ 이 $1,4$ 뿐일 때, $a_n=d(n-k)$ 의 $k$ 를 구하시오. (경계 $2,3$ 에서 등호)

📖 풀이 보기

$b_n=\tfrac12 d\cdot2^{\,n-2}=\tfrac{d}{2}\cdot2^{\,n-2}=d\cdot2^{\,n-3}$. $b_2=\tfrac12 d$, $b_3=d$.

여집합 $n=2,3$ 에서 $|a_n|\le b_n$ → $|n-k|\le2^{\,n-3}$.

$n=2$: $|2-k|\le2^{-1}=\tfrac12$ → $\tfrac32\le k\le\tfrac52$ (상한 $\tfrac52$).

$n=3$: $|3-k|\le2^0=1$ → $2\le k\le4$ (하한 $2$).

교집합 $2\le k\le\tfrac52$ … 한 점이 아님. 추가 경계 필요? $n=4$ 는 $>$(성립)이라 여집합 아님. 상한·하한이 겹치는 유일점을 주려면 문제 설계상 $n=2$ 상한과 $n=3$ 하한이 만나야 → 이 설정은 구간 $[2,\tfrac52]$.

정답: $2\le k\le\dfrac52$ (등호만으로 구간까지. 유일 확정은 추가 등호 조건 필요 — 함정: 항상 한 점은 아님).

교훈: 등호 부등식이 상수를 특정할 가능성을 열지만, 상·하한이 정확히 만나야 유일. 아니면 구간으로 남고 추가 조건이 필요하다.

✅ 학습자 가이드라인 · 검증

영상(권현석)의 논리를 중수준(하위 40%)도 따라오게 풀어 작성:

  • 여집합 해석 → "~뿐"을 반대 부등식(등호 포함)으로 (개념 ①, 기초 1).
  • 공차 인수분해 식세우기 → $a_n=d(n-k)$ 로 $d$ 약분, 미지수 $k$ 하나만 (개념 ③, 기본 1).
  • 등호 우선 → $k=\tfrac{10}{3}$ → $n=3,4$ 상·하한 교집합. 순수 파이썬으로 $|a_n|>b_n$ 이 $1,2,5$ 뿐임을 검산 (심화 1·2).
  • 대수 ↔ 그래프 교점 상호 검증 → $3,4,6$ 이 정확히 교점 (개념 ⑤).

다만 다음은 교사 검토 권장:

  • $d$ 결정 조건 — 원영상은 마지막 조건($a_?-b_?=1$)이 명확히 판서되지 않았습니다(보고서 "추정"). 본 자료는 $a_5-b_5=1$ 로 명시해 $d=3$ 으로 완결했습니다. 핵심($k=\tfrac{10}{3}$)은 완전 검산 완료. (핵심 ★★★, $d$ 조건 재구성 ★★)
  • "수능 대비"는 출제 패턴 라벨일 뿐 실재 기출이 아닙니다.
